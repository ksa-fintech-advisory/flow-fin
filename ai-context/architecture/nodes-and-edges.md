# Nodes & Edges

## Node Principles

Nodes represent financial semantics and operational meaning.

Examples:

* payment
* approval
* fraud check
* retry
* settlement
* routing
* reconciliation
* wallet
* transfer

Nodes are logical entities.
NOT visual shapes.

Visual shapes are merely representations.

---

## Edge Principles

Edges represent:

* relationships
* propagation
* execution movement
* orchestration transitions
* transaction flow
* runtime direction

Edges are NOT decorative SVG lines.

Edges represent actual runtime semantics.
