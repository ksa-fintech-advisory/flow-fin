# Context Loading Strategy

AI agents should load ONLY the relevant context sections for each task.

## By task type

### Rendering tasks

* `architecture/rendering.md`
* `ui/edge-rendering.md`
* `architecture/graph-layout.md`
* `ui/design-language.md`

### Runtime tasks

* `runtime/runtime-feel.md`
* `runtime/runtime-visualization.md`
* `runtime/propagation.md`
* `runtime/runtime-states.md`

### Animation tasks

* `ui/animation.md`
* `runtime/runtime-visualization.md`
* `runtime/propagation.md`

### Domain-specific work

* Relevant file(s) under `domains/`
* `architecture/nodes-and-edges.md`
* `runtime/runtime-states.md`

### New features (baseline)

* `core/product-vision.md`
* `phases/phase-1.md`
* `engineering/ai-rules.md`

Context precision is more important than context size.
